# Elham Mohmand | Portfolio Website

Personal portfolio website of **Elham Mohmand**, a front-end developer in training and English teacher from Herat, Afghanistan.

🔗 **Live website:** [https://elhammohmand2006-stack.github.io/My-portfolio/](https://elhammohmand2006-stack.github.io/My-portfolio/)

## About

This website shows who I am, my skills, and the projects I have built while learning front-end web development. It is fully responsive, so it works on phones, tablets and computers.

## Features

- Responsive design with a Bootstrap navbar and grid
- Typing animation in the hero section
- Smooth scroll animations when sections appear
- Hover effects on cards, skills and buttons
- Back-to-top button
- Project cards with links to live websites

## Built With

- HTML
- CSS
- Bootstrap 5
- JavaScript
- Git and GitHub (version control and hosting with GitHub Pages)
