# Elham Mohmand | Portfolio

A personal portfolio website for **Elham Mohmand**, front-end developer and UI designer.

**Live site:** https://elhammohmand2006-stack.github.io/My-portfolio/

## About

This website shows who I am, what I can build for clients, and my selected projects. It is fully responsive, so it works on phones, tablets and computers.

## Features

- Modern dark design with a **Day / Night mode** button
- Responsive layout for all screen sizes (with a menu for phones)
- Services section for my freelance work
- Project cards with a **filter** (HTML / CSS, JavaScript, Framer, Figma)
- Live demo and code links for each project
- Smooth scroll animations and a moving skills strip
- Download CV button

## Built with

- HTML
- CSS (Grid, Flexbox, variables, animations)
- JavaScript (project filter, theme toggle, mobile menu, scroll animation)
- Google Fonts: Syne, Poppins and Playfair Display

## Run it on your computer

1. Download or clone this repository.
2. Open `index.html` in your browser.

No installation is needed.

## How to edit

- **Colors:** change the values at the top of `style.css` (inside `:root` and `body.day`).
- **Add a project:** copy one `<article class="card">` block in `index.html`, then change the image, title, text and links. Put the screenshot in `images/projects/`.
- **Change the photo:** replace `images/elham.jpg` with a new photo that has the same name.
